# Example texts: attribution and reuse

This folder contains two French literary examples used for Fabula demos:

- `tartarin.txt`: **Alphonse Daudet**, *Tartarin sur les Alpes*.
- `lassomoir.txt`: **Émile Zola**, *L'Assommoir*.
